# 喝一杯（Drink One）

## 产品需求文档（PRD v1.0）

# 1. 项目背景

现代年轻人在聚会、独处、观影、游戏、社交等场景下，经常面临：

* 今天喝什么？
* 什么酒适合我？
* 想微醺应该喝什么？
* 聚会应该买什么酒？
* 哪些酒值得尝试？

市面上的酒类应用大多偏向电商或百科。

本产品定位：

> 酒类推荐 + 酒文化探索 + DIY酒谱 + 品鉴记录

而非酒类销售平台。

---

# 2. 产品定位

产品名称：

喝一杯

Slogan：

今晚，喝一杯。

产品类型：

微信小程序

目标用户：

20-40岁酒类消费者

产品核心：

帮助用户快速决定喝什么酒。
